# Documentação do @arapucajs/eslint-plugin

Este índice organiza a documentação para quem instala, usa, mantém ou desenvolve o plugin. Os arquivos descrevem o comportamento observado no código e nos manifests do repositório.

## Guias

- [Instalação e configuração](guides/installation-and-configuration.md): dependências, flat config, habilitação de regras e configuração de `allowed`.
- [Desenvolvimento e verificações](guides/development.md): estrutura local, scripts, harness dos testes, build e fluxo de contribuição.

## Referências

- [Referência das regras](reference/rules.md): comportamento, opções, mensagens, correções e limites das cinco regras.
- [Manifesto e comandos](reference/package-and-commands.md): exports, compatibilidade, arquivos empacotados e scripts definidos no `package.json`.
- [CI, release e publicação](reference/automation.md): workflows existentes e sequência de publicação.

## Arquitetura

- [Visão arquitetural](architecture/overview.md): fluxo de configuração, carregamento das regras e principais decisões de implementação.

## Planejamento e manutenção

- [Planejamento de manutenção](planning/maintenance.md): checklist contínuo, pontos conhecidos que merecem avaliação e critérios para manter a documentação sincronizada. Não é uma promessa de funcionalidades futuras.
